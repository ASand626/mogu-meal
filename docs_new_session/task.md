# アプリ開発のタスク一覧（メールアドレスログイン改修まですべて完了！）

これまでのすべてのバグ修正、第2段階のUX向上、およびご指示いただいた**「メールアドレス（ログインID）認証の追加 ＆ 添付モックアップ準拠のログイン画面への改修」**が完璧に完了し、ローカルでのビルド検証も成功しています。

## 済（すべてのタスクが完璧に完了！）

- [x] **Firebase Auth Googleログインのシンプル化**
  * `delete()` 処理を廃止し、ログインを一本化。待機時間を劇的に改善。
- [x] **ログアウト時のキャッシュ消去**
  * `logout` 時に `localStorage` をクリアし、古いデータとの競合を排除。
- [x] **設定画面（/settings）でのデータ自動同期**
  * `useEffect` による Firestore データのロード検知・自動反映を追加。デフォルト値による上書きバグを完全解決。
- [x] **ゲストモード機能の基礎実装**
  * ログイン画面に「ログインせずに使う（ゲストモード）」ボタンを追加。
- [x] **手動ログイン時の「読み込み中」画面の表示仕様の改善（UX向上）**
  * `AppContext.tsx` の `onAuthStateChanged` 内にある `setLoadingAuth(true)` の強制呼び出しを削除し、オートログイン時のみに限定。
  * `isLoggingIn` ステートを導入し、手動ログイン時の二重クリックを完全に防止。画面全体をブロックせずにログインモーダルの内側で「ログイン中 / データを同期中...」の上品なインジケータを表示する極上のUXを構築。
- [x] **誤作動防止用のアカウントメニュー（ドロップダウンメニュー）の追加 ＆ プレミアム化**
  * `AuthButton.tsx` にドロップダウンメニュー用のステート（`isOpen`）を追加。
  * `framer-motion` によるふわっと展開するアニメーション（`origin-top-right`）を適用。モバイルはみ出し防止。
- [x] **メールアドレス/パスワード認証機能の追加**
  * `AppContext.tsx` に `loginWithEmail`, `signUpWithEmail`, `resetPassword` 関数を追加。
  * Firebase Auth SDK の `signInWithEmailAndPassword`, `createUserWithEmailAndPassword`, `sendPasswordResetEmail` を安全かつ状態追跡（`isLoggingIn`）に対応した形で実装。
- [x] **モックアップに準拠したログイン画面の改修**
  * `AuthGuard.tsx` を大幅に刷新。
  * 添付されたモックアップ画像に基づき、カード型コンテナ内に「ログインID」「パスワード」のラベルと入力欄、「パスワードをお忘れですか？」リンク、「ログインする」ボタン、「新規登録」ボタン、「ログインせず使用する」リンクを忠実に配置。
  * 追加要件「Googleアカウントでのログイン」をデザインに調和する形で境界線（「または Googleアカウントでログイン」）の下にGoogleアイコン付きボタンとしてエレガントに統合。
  * `framer-motion` の `AnimatePresence` を使った、ログイン ⇄ 新規登録 ⇄ パスワード再設定 のスライド ＆ フェード切り替えトランジションを適用。
  * Firebaseの各種エラー（メール形式不正、パスワード一致エラー、アカウント重複、脆弱パスワード等）を親切な日本語エラーメッセージへマッピング。
- [x] **型チェック ＆ ビルド検証**
  * `npm run build` を実行し、型チェックエラーが0件かつ Next.js のプロダクションビルドが正常にパスすることを確認。

# 新セッション引き継ぎ用：タスク一覧

これまでの作業状況と、新しいチャットで最初に取り組むべきタスクの整理です。

## 済（第1段階：修正・追加完了）
- [x] **Firebase Auth Googleログインのシンプル化**
  * `delete()` 処理を廃止し、ログインを一本化。待機時間を劇的に改善。
- [x] **ログアウト時のキャッシュ消去**
  * `logout` 時に `localStorage` をクリアし、古いデータとの競合を排除。
- [x] **設定画面（/settings）でのデータ自動同期**
  * `useEffect` による Firestore データのロード検知・自動反映を追加。
- [x] **ゲストモード機能の基礎実装**
  * ログイン画面に「ログインせずに使う（ゲストモード）」ボタンを追加。
  * `isGuest = true` の際は `AuthGuard` を通過させ、`localStorage` や Firestore への書き込みを行わずメモリ上（State）だけで動作する仕様に。
